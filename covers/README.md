# 大廳封面圖

每款遊戲一張，檔名就是遊戲資料夾名稱，例如 `covers/proxy-war.webp`。

- 尺寸：1536×640（12:5），WebP，單張盡量在 200 KB 以內
- 左邊約 45% 留給大廳疊上去的中文標題、英文副標和一句標語，畫面重點放在右半邊
- 手機版會把上下各裁掉約 10%，重點請放在中間 80% 高度內
- `covers/hero.webp`（選用）：電腦版標語右側的遊戲盒主視覺，透明背景。有這張就取代程式畫的盒子
- 如果封面圖本身已經印好標題，把 `index.html` 裡那款遊戲加上 `textInArt:1`，大廳就不會再疊字

檔案名稱：proxy-war、blank-agents、unsigned、seven-days、wealth-road、red-envelope、office-mole、er-24、cat-cafe、influencer、pudu、taipei-rent、magic-exam、claw-master、time-pawn、stock-tycoon、futures-warrior
